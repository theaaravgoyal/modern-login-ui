# Modern Login UI

A modern and responsive login page built using React, Tailwind CSS, HTML, and CSS.

## Preview

Clean UI with:

- Modern design
- Smooth animations
- Responsive layout
- Interactive elements
- Clean code structure

## Tech Stack

- React
- Tailwind CSS
- HTML5
- CSS3
- JavaScript

## Installation

Clone the repository

Go to project directory:

cd modern-login-ui

Install dependencies:

npm install

Start development server:

npm run dev

## Features

- Responsive login page
- Modern UI/UX
- Smooth transitions
- Mobile-friendly design
- Clean and reusable components
